# 🧠 Math Quiz Game (C++)

A console-based **Math Quiz Game** built using **C++** that generates random arithmetic questions with multiple difficulty levels and operation types.

The program allows the user to practice math skills while receiving instant feedback and a detailed final result at the end of the quiz.

---

# 🎮 Features

✔ Generate random math questions
✔ Multiple difficulty levels
✔ Multiple operation types
✔ Instant feedback after each answer
✔ Colored console feedback
✔ Final quiz statistics
✔ Simple and clean console interface

---

# 🧩 Difficulty Levels

| Level  | Description           |
| ------ | --------------------- |
| Easy   | Numbers from 1 → 10   |
| Medium | Numbers from 10 → 50  |
| Hard   | Numbers from 50 → 100 |
| Mix    | Random difficulty     |
